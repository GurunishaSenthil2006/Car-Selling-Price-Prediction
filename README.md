# Car-Selling-Price-Prediction

A machine learning project to predict the selling price of cars based on their details and seller information.

## Inputs
- **Car Details:** Showroom Price, Kilometers Driven, Purchase Year, Number of Previous Owners  
- **Additional Info:** Fuel Type, Seller Type, Transmission, Seller Location  

## Tech Stack
- **Language:** Python
- **Libraries:** pandas, numpy, scikit-learn, matplotlib, seaborn, pickle
- **Framework:** Streamlit
- 
## Usage
1. Run the app:  
   ```bash
   streamlit run app.py
